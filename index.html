SUSPENSION SYSTEM

汽车悬挂系统 · 综合可视化项目

本项目汇集四个独立视角的可视化页面，从结构几何、控制理论、振动特性 与相空间四个层面观察同一套汽车悬挂系统。点击下方任意卡片进入对应模块。

VIEW 01

麦弗逊式独立前悬挂系统

3D 教学模型：可旋转缩放的整车前悬挂总成，支持零件高亮、中文标签、实时读数与爆炸拆解演示，直观理解各部件装配关系与拆装路径。

three.js · 需联网 3D 交互 爆炸视图
VIEW 02

悬挂系统控制理论实验平台

基于 1/4 汽车被动悬挂数学模型的仿真实验台：调节质量 m、刚度 k、阻尼 c 与输入激励，实时观察时域响应、Bode 频域特性与相平面轨迹。

Plotly · 需联网 时域 / 频域 相平面
VIEW 03

弹簧轮胎系统 · 竖向振动

轻量 Canvas 互动演示：以弹簧—轮胎—簧载质量构成的竖向振动模型，动态展示路面激励下的振动响应与能量在弹簧、阻尼间的传递过程。

Canvas 竖向振动 零依赖
VIEW 04

相空间可视化计算器

把任意微分方程变成相图：一/二/三维相空间、向量场、相流与不动点分类，可写 mÿ + cẏ + ky = cẋ + kx 这类学生写法，并按 m/c/k 实时观察悬挂响应；另有随机路面下的蒙特卡洛概率密度与功率谱。含四层自动化验收。

Canvas 零依赖 · 双击可用 随机振动 / PSD 319+ 项断言

目录结构

  • index.html — 本导航首页
  • assets/theme.css — 共享设计层（唯一配色来源）
  • modules/macpherson-3d-model.html
  • modules/suspension-control-lab.html
  • modules/spring-tire-vibration.html
  • modules/phase-space-calculator/ — 多文件项目

运行方式

四个模块都是静态页面：VIEW 03 / 04 双击即可打开（VIEW 04 完全离线自足）； VIEW 01 / 02 依赖 CDN，需要通过 http 协议访问，可在本目录启动任意静态服务器后浏览。

外部依赖

VIEW 01 依赖 three.js（jsDelivr）、VIEW 02 依赖 Plotly.js（cdn.plot.ly），首次访问需联网； VIEW 03 与 VIEW 04 无任何外部依赖。

风格约定

四个模块共用 STYLE.md 与 assets/theme.css：同一套配色、字体、圆角与页面外壳， 各页面只差布局。新增模块请照此接入。
