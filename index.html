SUSPENSION SYSTEM

汽车悬挂系统 · 综合可视化项目

本项目汇集三个独立视角的可视化页面，从结构几何、控制理论与振动特性 三个层面观察同一套汽车悬挂系统。点击下方任意卡片进入对应模块。

VIEW 01

麦弗逊式独立前悬挂系统

3D 教学模型：可旋转缩放的整车前悬挂总成，支持零件高亮、中文标签、实时读数与爆炸拆解演示，直观理解各部件装配关系与拆装路径。

three.js 3D 交互 爆炸视图
VIEW 02

悬挂系统控制理论实验平台

基于 1/4 汽车被动悬挂数学模型的仿真实验台：调节质量 m、刚度 k、阻尼 c 与输入激励，实时观察时域响应、Bode 频域特性与相平面轨迹。

Plotly 时域 / 频域 相平面
VIEW 03

弹簧轮胎系统 · 竖向振动

轻量 Canvas 互动演示：以弹簧—轮胎—簧载质量构成的竖向振动模型，动态展示路面激励下的振动响应与能量在弹簧、阻尼间的传递过程。

Canvas 竖向振动 零依赖

目录结构

  • index.html — 本导航首页
  • modules/macpherson-3d-model.html
  • modules/suspension-control-lab.html
  • modules/spring-tire-vibration.html

运行方式

三个模块均为独立单页，双击即可在浏览器中打开。若需通过 HTTP 访问，也可在本目录启动任意静态服务器后浏览首页。

外部依赖

模块 01 依赖 three.js（jsDelivr CDN，且需通过 http/https 协议打开），模块 02 依赖 Plotly.js（cdn.plot.ly）。首次访问需联网；模块 03 无任何外部依赖。
