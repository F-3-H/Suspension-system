四分之一车模型，只看簧上共振这个最烈工况：路面激励幅值 X = 0.05 m， 作用频率取当前固有频率 ωn = √(k_eff/m)，簧载质量 m = 300 kg。

弹簧支路等效刚度 k_eff = 1 / (1/k_弹簧 + 1/k_顶胶)
相对位移幅值 A = X·√(k_eff·m) / c　　弹簧力 Fk = k_eff·A　　阻尼力 Fc = c·ωn·A
总成合力 Fs = √(Fk² + Fc²)（＝传到车身的动态轮荷）　　每周期耗散 W = π·c·ωn·A²
下控制臂支路 F_arm = 0.45·Fs　　横向稳定杆 F_bar = 0.30·F_arm（示意的几何分担系数）

退化就是"慢的外因经由零件自己的内因起作用"：单位时间内，零件坏多少，取决于它自己承受着多大的作用。

dh/dt = −λ · (驱动 / 驱动₀)

弹簧、顶胶、衬套、球头、转向节、稳定杆、副车架、车身：驱动＝行程幅值 A； 减震器：驱动＝它自己耗散的功率 W；轮毂轴承：驱动＝累计里程。 各 λ 由"8 年后的健康度"反解（迭代求得，页面自己算）。

关键在这里：A 与 W 都出现在 k_eff、c 的式子里，而 k_eff、c 又由零件决定—— 一件坏，另一件的驱动就变大，于是互相推着坏。所以年份越靠后，同样一年掉得越多。

本项目的 tools/gen-parts-state.py 用 Python 独立算了一遍同样的式子， 页面上这组数字与它 0–8 年逐年比对过。 数字是示意的粗糙模型，量级取自真实减震器与弹簧，不是实测值。
