# 悬挂系统随机路面分析

> 「汽车悬挂系统 · 综合可视化项目」的 **VIEW 05**。配色、排版与页面外壳遵循仓库的
> [`STYLE.md`](../../STYLE.md) 与 [`assets/theme.css`](../../assets/theme.css)；
> 本项目为离线自足，`styles.css` 里保留了一份与共享主题**同值**的 token 兜底（拷走整个目录也能双击运行），
> 两份是否同步由 `node ../../tools/verify-repo-style.cjs` 检查。
>
> 与其他四个视角共用同一套参数记法：**m 质量、c 阻尼、k 刚度、x 路面位移、y 车身位移**。

求 `y(t)` 的拉氏变换在随机输入下失效之后，换一条路走：**不从"某一条"随机的时程里找确定，
而从随机路面的频率构成里找确定**——用功率谱密度取出"变中的不变"，
再乘上悬挂内因的频率响应 `|H(f)|²`，得到真正作用在车身上的影响谱。

**双击 `index.html` 即可运行**（纯静态、无构建、无网络依赖、无 CDN）。

## 一、七个面板各自回答什么

| 面板 | 看什么 |
|---|---|
| ① 随机路面 x(t) 与车身 y(t) | 外因输入的时域全貌：x(t) 完全随机，y(t) 的中高频被内因隔离而明显变小 |
| ② 频率占比图 | 对 x(t) 做 Welch 功率谱：曲线是各频率的能量密度，柱状是**频段能量占比** ∫S<sub>x</sub>df / 总能量。等级只等比放大总能量，占比按定义不变——**柱状不动才是对的** |
| ③ 悬挂内因响应 \|H(f)\| | 内因对哪些频率敏感：位移传递 \|H_d\| 与加速度传递 \|H_a\|，共振峰在固有频率 f_n |
| ④ 综合影响 S<sub>out</sub>(f) = \|H(f)\|²·S<sub>x</sub>(f) | 把"路面有多少该频率"与"系统对它多敏感"相乘，才是真正的影响；柱状为影响频段占比 |
| ⑤ 相空间概率云 (y, ẏ) | N 条随机路面下重复演化的 (y, ẏ) 密度：云越宽越颠簸，云越高震动越快 |
| ⑥ 路面等级 → 影响 | 固定内因逐级换路，σ<sub>a</sub> 随 ISO 等级单调上升（纵轴对数），红竖线为当前等级 |
| ⑦ 指标与内外因改进 | 六项指标 + 由内因（阻尼/固有频率/优化解）与外因（车速/路面等级）两侧给出的文字建议 |

## 二、怎么用

- **外因**：路面等级（ISO 8601 的 A–H）、车速、空间频率指数 w、随机种子（可"换一条"）
- **内因**：簧上质量 m、阻尼系数 c、弹簧刚度 k；派生量 f<sub>n</sub>、ζ 以读数给出、跟着联动
- **优化约束**：给出允许的 RMS 行程，点「自动优化内因 (c, k)」把当前路面下满足行程约束、
  且 RMS 加速度最小的 (c, k) 填回滑杆
- 拖动任一滑杆，①③④⑦ 立即联动；相空间（⑤）与优化结果为重路径，去抖后才重算

## 三、物理口径

- **随机路面**：ISO 8601 空间功率谱 `G_d(n) = G_d(n₀)·(n/n₀)^(−w)`，`n₀ = 0.1 cycle/m`；
  按车速换算为时间频率谱 `S(f) = G_d(n)/v`，再用**随机相位频域合成**得到 x(t)（与 ẋ(t) 同源）。
  A–H 级的 `G_d(n₀)` 逐级翻倍，**幅值跨 128 倍**（功率跨 16384 倍）。
- **频段占比**：占比 = ∫S df / ∫S df（全带），**带宽就是权重**。
  所以带宽最宽的 15–25 Hz 频段在影响占比里可以最大，尽管它的平均谱密度最低。
- **影响谱**：`S_out(f) = |H(f)|²·S_x(f)`，其中 1 自由度悬挂的位移/加速度传递由 m、c、k 决定，
  `f_n = √(k/m)/2π`、`ζ = c/(2√(mk))`。
- **与等级无关的量**：等级在 ②④ 的占比里是**公共因子，被占比约掉**，所以占比不随等级变化；
  随等级变的是总量（PSD 电平、σ<sub>a</sub>）。这两件事都在面板里用动态读数写明。
- **等级扫描（⑥）**：等级只等比缩放 S_x，故 σ ∝ √G_d0，可直接解析外推，不需要重算。


## 五、并入仓库时做了什么

本轮把该项目并入「汽车悬挂系统」仓库，**只做外观统一与目录归位，不改动物理与数值实现**：

- 接入共享主题：`<link>` `../../assets/theme.css`，`styles.css` 顶部保留一份同值 token 兜底；
- 页面外壳换成仓库统一的 `.sitebar`（品牌可回导航页 + `VIEW 05` 面包屑 + 依赖标签）与 `footer.site-foot`；
  原来那条"随机路面 → … → 指导改进"的流程链保留为顶栏下方的一条 `chainbar`；
- 目录改为 `index.html / styles.css / src/ / README.md`，`css/` 与 `js/` 归并；
- 画布取色改用主题 token 的值并注明（数据系列取 `--s1…--s5`，语义随仓库统一：橙=路面、蓝=位移、
  绿=影响、紫=加速度传递、红=固有频率标线），`plot.js` 的轴线/网格/文字取 `--line-strong / --line / --fg-mute`。

此前在源项目里修掉的两处"看着像 bug 的物理"也一并带进来：

1. **改等级时 ②④ 的柱状占比不动** —— 这不是渲染故障：等级是公共因子，被占比约掉了。
   界面改为用**动态读数**说明"曲线电平随等级整体升降、柱状占比不变"，② 另画一条固定的
   **C 级参考谱**当标尺，一眼能看出等级差。
2. **外因只等比缩放幅度时，自动定标的视图会把它归一化掉** —— 于是 ① 的纵轴改用
   **symlog 压缩刻度 + 固定量程**：压缩拐点锚在 C 级 σ、量程锚到 H 级，两者都与等级无关，
   换等级时波形高度逐级变化且永不裁切；跨等级的绝对比较另有 ⑥ 的对数图兜底。

## 六、已知边界

- 模型为 **1 自由度简化模型**（与"内因篇"一致），分析频带 0.1–25 Hz，加速度为**未计权 RMS**，
  只用于相对比较，不与标准计权舒适度限值直接对号。
- 相空间概率云为可视化目的做了降规模（12 组 × 1024 点），是定性形状，不是精确分布。
- 本模块目前**没有自动化验收**，靠人工目视与浏览器控制台检查（与 VIEW 01 / 02 / 03 同）；
  仓库全局的风格与链接一致性由 `node ../../tools/verify-repo-style.cjs` 覆盖。
