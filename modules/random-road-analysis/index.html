优化约束

依据《工控论——悬挂系统内因篇》《工控论——相空间与功率谱密度》的思路建立： 随机路面的变中取不变的频率构成，再以内因响应衡量其对系统的影响。 模型为 1 自由度简化模型（与内因篇一致），分析频带 0.1–25 Hz，加速度为未计权 RMS。

① 随机路面 x(t) 与车身 y(t) 外因输入

x(t) 时域完全随机（“变”）；y(t) 明显小于 x(t)，中高频被内因隔离。

② 频率占比图 变中的不变

对 x(t) 做功率谱密度（Welch 统计）：曲线为各频率能量密度，柱状为频段能量占比 = ∫Sxdf / 总能量。等级只把总能量等比放大，各频段占比按定义不变——柱状不动是正确结果（“变中的不变”）；电平的变化看曲线相对红色 C 级参考谱的整体升降。

③ 悬挂内因响应 |H(f)| 内因

同一路面下，内因决定它对哪些频率敏感（共振峰在 fn）。

④ 综合影响：Sout(f) = |H(f)|² · Sx(f) 影响有多大

把“路面有多少该频率”和“系统对它的敏感度”相乘，才是真正的影响；柱状为各频段的影响占比 = ∫Sadf / 总能量，带宽就是权重——所以最宽的高频段占比可以最大，尽管它的谱密度最低（见上方曲线）。影响占比与等级无关：等级是公共因子，被占比约掉。

⑤ 相空间概率云 (y, ẏ) 随机中的稳定

N 条随机路面下重复演化：云越宽越颠簸，云越高震动越快。

⑥ 路面等级 → 影响 外因扫描

固定内因（m、c、k）逐级换路：σa 随 ISO 等级单调上升，纵轴为对数（A→H 跨 128 倍）。红色竖线为当前等级。
